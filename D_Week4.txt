■ งานที่ดำเนินการในวันนี้
────────────────────────────────────────────────────────────────────────

1. แก้ไขปัญหา main.py หยุดทำงานเองโดยไม่ตั้งใจ
   ─────────────────────────────────────────────────────────────────
   เพิ่ม restart loop ใน __main__ ของ main.py เพื่อให้โปรแกรม
   รีสตาร์ทอัตโนมัติเมื่อเกิดข้อผิดพลาด (Exception) ใดๆ
   โดยรอ 3 วินาทีก่อนรีสตาร์ท และยังคงสามารถหยุดโปรแกรมได้ตามปกติ
   ด้วยการกด q, ESC หรือ Ctrl+C

2. รวมหน้า Camera และหน้าข้อมูลวันนี้เป็นหน้าเดียว
   ─────────────────────────────────────────────────────────────────
   - ย้ายเนื้อหาทั้งหมดของ DashboardView.vue เข้ารวมใน CameraView.vue
     โดยวางส่วนกล้องไว้ด้านบน และส่วนข้อมูลวันนี้ไว้ด้านล่าง
   - อัปเดต router/index.js ให้มีเพียง route เดียวที่ path "/"
     ซึ่ง AppNav จะแสดงเมนูเพียงรายการเดียวโดยอัตโนมัติ
   - นำเข้า composables ทั้ง useAttendance และ useLiveSession
     และ component StatCard, PersonCard, AttendanceFeed, HourlyChart,
     OrgBreakdown เข้ามาใน CameraView.vue ด้วย

3. ลบการแสดงแหล่งที่มาของกล้อง (Camera Source)
   ─────────────────────────────────────────────────────────────────
   ลบ cameraSource ออกจาก 2 จุดใน CameraView.vue ได้แก่
     • แถบ Controls ด้านล่างหน้าจอกล้อง
     • ส่วน "สถานะระบบ" ในแผงขวา (บล็อก "แหล่งกล้อง")
   รวมถึงลบ ref, constant และฟังก์ชัน fetchCameraInfo() ที่เกี่ยวข้องออก

4. เพิ่มฟีเจอร์ขยายหน้าจอกล้อง (Fullscreen)
   ─────────────────────────────────────────────────────────────────
   - เพิ่มปุ่ม "ขยาย / ย่อ" พร้อม hint ชื่อ shortcut [F]
     ในแถบ controls ด้านล่างหน้าจอกล้อง
   - เพิ่ม keyboard listener สำหรับกด F เพื่อ toggle fullscreen
     โดยไม่ทำงานเมื่อ focus อยู่ใน input หรือ textarea
   - ใช้ Browser Fullscreen API (requestFullscreen / exitFullscreen)
     บน element ของหน้าจอกล้องโดยตรง
   - ติดตามสถานะ fullscreen ผ่าน fullscreenchange event
     เพื่ออัปเดตข้อความปุ่ม "ขยาย ↔ ย่อ" แบบ real-time
   - เพิ่ม CSS scoped สำหรับ layout เมื่ออยู่ในโหมด fullscreen
     ให้ภาพวิดีโอเต็มพื้นที่หน้าจอ

■ สรุปไฟล์ที่สร้าง / แก้ไข
────────────────────────────────────────────────────────────────────────

  [แก้ไข] main.py
    → เพิ่ม restart loop ใน __main__

  [แก้ไข] dashboard/src/views/CameraView.vue
    → รวมเนื้อหา DashboardView เข้ามาทั้งหมด (template + script)

    → เพิ่มปุ่ม fullscreen + keyboard listener (F key)
    → เพิ่ม CSS scoped สำหรับโหมด fullscreen

  [แก้ไข] dashboard/src/router/index.js
    → ลด route เหลือ 1 รายการ (path "/" → CameraView)
    → ลบ import DashboardView ออก

■ งานที่ดำเนินการในวันนี้
────────────────────────────────────────────────────────────────────────

1. พัฒนาระบบ Web Dashboard สำหรับระบบ Face Attendance (ต่อเนื่อง)
   ─────────────────────────────────────────────────────────────────
   พัฒนาหน้า Dashboard บนเว็บให้สามารถแสดงผลข้อมูลแบบ real-time
   เชื่อมต่อกับระบบ Face Recognition (main.py) ที่ทำงานอยู่เบื้องหลัง

2. เพิ่มระบบ Live Detection บน Dashboard
   ─────────────────────────────────────────────────────────────────
   - สร้างกลไก IPC (Inter-Process Communication) ผ่านไฟล์ live_state.json
     โดย main.py จะเขียนข้อมูลสถานะปัจจุบันลงไฟล์ดังกล่าวทุก 1 วินาที
   - เพิ่ม API endpoint GET /session/live ใน api.py
     เพื่ออ่าน live_state.json และส่งข้อมูลไปให้ Dashboard
   - สร้าง composable useLiveSession.js สำหรับ polling ข้อมูลทุก 2 วินาที

3. สร้าง Component สำหรับแสดงผล Liveness Status
   ─────────────────────────────────────────────────────────────────
   - LiveDetection.vue  — แสดงรายชื่อบุคคลที่กล้องตรวจพบในขณะนั้น
                          พร้อมสถานะ liveness แบบ real-time
   - LivenessBadge.vue  — Badge แสดงสถานะ liveness แต่ละระดับ ได้แก่
       • confirmed  (เขียว)  — ผ่านการตรวจสอบ liveness ครบทุกด่าน
       • pending    (เหลือง) — อยู่ระหว่างการตรวจสอบ พร้อมแสดงด่านที่ค้างอยู่
       • challenge  (ม่วง)   — อยู่ระหว่างทดสอบ Finger Challenge
       • failed     (แดง)    — ล้มเหลวการตรวจสอบ พร้อมแสดงสาเหตุ

4. ปรับปรุง DashboardView.vue
   ─────────────────────────────────────────────────────────────────
   เพิ่ม section LiveDetection ในหน้า Dashboard หลัก
   วางระหว่าง Person Cards (สรุปรายวัน) และ Attendance Feed (ตารางรายการ)
   เพื่อให้เห็นทั้งข้อมูลประวัติและสถานะ real-time ในหน้าเดียวกัน

5. แก้ไข Bug — รูปแบบเวลา first_seen / last_seen ใน main.py
   ─────────────────────────────────────────────────────────────────
   เปลี่ยนจาก strftime("%H:%M:%S") เป็น isoformat()
   เพื่อให้ JavaScript สามารถ parse ค่าวันที่-เวลาได้อย่างถูกต้อง

■ สรุปไฟล์ที่สร้าง / แก้ไข
────────────────────────────────────────────────────────────────────────

  [แก้ไข] api.py
    → เพิ่ม GET /session/live endpoint อ่าน live_state.json
    → คืนสถานะ active, stale, persons พร้อม liveness ของแต่ละคน

  [แก้ไข] main.py
    → แก้ first_seen/last_seen ให้ใช้ .isoformat() แทน strftime

  [ใหม่]  dashboard/src/composables/useLiveSession.js

  [ใหม่]  dashboard/src/components/LivenessBadge.vue
    → Badge สำหรับแสดง liveness state 4 ระดับ (confirmed/pending/challenge/failed)

  [ใหม่]  dashboard/src/components/LiveDetection.vue
    → Section แสดงบุคคลที่กล้องตรวจพบ + สถานะ liveness แบบ real-time
    → แสดง offline banner เมื่อ main.py ไม่ได้ทำงาน

  [แก้ไข] dashboard/src/views/DashboardView.vue
