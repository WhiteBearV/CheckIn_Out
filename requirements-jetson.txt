#
#  ⚠️  อย่าใช้ requirements.txt ตัวเดิม — นั่น freeze มาจากเครื่อง x86_64 + GPU desktop
#      (torch+cu126, nvidia-*-cu12, onnxruntime-gpu PyPI ฯลฯ ลง Jetson ไม่ได้)
#
#  Jetson: CUDA / cuDNN / TensorRT มากับ JetPack ในระบบอยู่แล้ว
#          → ไม่ต้องลง nvidia-*-cu12 ใดๆ ผ่าน pip
#
#  ตั้งค่าก่อนรันบน Jetson (ตัดด่าน 6 MiniFASNet ที่ลาก torch/tensorflow มา):
#      config.py / profile :  FAS_ENABLED = False
#      → liveness_engine จะไม่ import deepface เลย (lazy import ถูก guard ด้วย flag)
#      → anti-spoof ยังทำงานครบ ด่าน 1-5 (depth, motion, blink, texture, finger)
#
# ─────────────────────────────────────────────────────────────────────
#  ขั้นที่ 1 — ติดตั้งด้วย "วิธีเฉพาะ Jetson" ก่อน (อย่า pip install จากไฟล์นี้)
# ─────────────────────────────────────────────────────────────────────
#
#  [onnxruntime-gpu]  หัวใจของ InsightFace — ต้องเป็น wheel ที่ build กับ CUDA ของ JetPack
#      ดาวน์โหลด wheel aarch64 ให้ตรง JetPack/Python จาก Jetson Zoo:
#        https://elinux.org/Jetson_Zoo#ONNX_Runtime
#      เช่น (เวอร์ชันต้อง match JetPack จริง):
#        pip install onnxruntime_gpu-<ver>-cp310-cp310-linux_aarch64.whl
#
#  [opencv]  แนะนำใช้ตัวที่มากับ JetPack (build พร้อม CUDA แล้ว) — ตรวจด้วย:  python3 -c "import cv2; print(cv2.__version__)"
#            ถ้าไม่มีค่อย  pip install opencv-python  (จะได้ build CPU ธรรมดา)
#
#  [mediapipe]  PyPI aarch64 wheel มีจำกัด/ไม่รองรับ GPU บน Jetson
#               ดู wheel เฉพาะ Jetson:  https://github.com/jetson-nano-wheels หรือ Jetson Zoo
#
# ─────────────────────────────────────────────────────────────────────
#  ขั้นที่ 2 — ตัวที่เหลือ ลงผ่าน pip ได้ (มี aarch64 wheel หรือ pure-python)
#      pip install -r requirements-jetson.txt
# ─────────────────────────────────────────────────────────────────────
