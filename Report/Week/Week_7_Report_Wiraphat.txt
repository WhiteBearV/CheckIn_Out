        การ Implement ใน stream_server.py ได้แยก Spawn Logic ออกเป็น Helper _spawn_main_proc() และ _spawn_api_proc() เพื่อให้ทั้ง /system/start และ Watchdog เรียกใช้ร่วมกัน เพิ่ม _record_restart() ติดตาม Timestamp ใน Window 60 วินาที, _watchdog_loop() เป็น Daemon Thread ตรวจทุก 3 วินาทีพร้อม Grace Period 8 วินาทีหลัง Spawn ใหม่เพื่อกัน Race Condition และเพิ่ม Endpoint GET /system/watchdog สำหรับดูสถานะและ Restart History พร้อมตั้ง @app.on_event('startup') ให้ Start Watchdog ตั้งแต่ Boot นอกจากนี้ได้สร้างโฟลเดอร์ deploy/ ใหม่ที่บรรจุ facereg-stream.service เป็น systemd Unit File พร้อมตั้ง Restart=always, RestartSec=3 และ KillMode=mixed สำหรับให้ SIGTERM กระจายถึง Subprocess และ install_service.sh สคริปต์ติดตั้งที่ Copy ไปยัง /etc/systemd/system พร้อม daemon-reload และ enable Service สุดท้ายอัปเดต CLAUDE.md เพิ่มหัวข้อ Watchdog และทดสอบ Smoke ผ่านทุกเคสรวมทั้ง Rate Limit ที่ Disable ตัวเองหลังเกิน 5 ครั้ง
