2. Authentication Flow (Phase 1.4 — Login + JWT)
=================================================

  Browser                  stream_server.py            PostgreSQL.users
  ─────────                ─────────────────           ────────────────
     │                            │                          │
     │  POST /auth/login          │                          │
     ├───────────────────────────►│  SELECT * FROM users     │
     │  {username, password}      ├─────────────────────────►│
     │                            │  WHERE username=?        │
     │                            │◄─────────────────────────┤
     │                            │  user row + bcrypt hash  │
     │                            │                          │
     │                            │  bcrypt.checkpw()        │
     │                            │  ✓ ตรง                   │
     │                            │                          │
     │                            │  UPDATE last_login=NOW() │
     │                            ├─────────────────────────►│
     │                            │                          │
     │                            │  jwt.encode(             │
     │                            │    sub=user_id,          │
     │                            │    role='admin',         │
     │                            │    exp=now+8h)           │
     │  200 OK                    │                          │
     │  {token, role,             │                          │
     │◄───────────────────────────┤                          │
     │   must_change_password}    │                          │
     │                            │                          │
     │  localStorage.setItem      │                          │
     │  ('fr_token', token)       │                          │
     │                            │     audit.log(           │
     │                            │       'auth.login.success'
     │                            ├─────────────────────────►│ INSERT audit_logs
     │                            │       user, ip, ua)      │
     │                            │                          │
     │  ทุก request หลังจากนี้:    │                          │
     │  Authorization: Bearer <T> │                          │
     ├───────────────────────────►│  jwt.decode() verify     │
                                  │  → user dict             │
                                  │  → require_admin?

  ── Rate Limit (Phase 1.3) ──
  ถ้าใส่รหัสผิด > 5 ครั้ง/นาที/IP → 429
  {"detail": "คุณใส่รหัสผิด 5 ครั้งติดต่อกัน — กรุณาลองใหม่ในอีก 1 นาที"}

  ── Force Change (Phase 1.4) ──
  ถ้า must_change_password=TRUE → frontend redirect /change-password
  RequireAuth block ทุก route อื่น จนกว่าจะเปลี่ยนรหัส


3. Face Recognition + Attendance Flow (Per-Frame)
==================================================

  Camera           main.py worker thread             external API + DB
  ─────────        ─────────────────────             ─────────────────
     │
     │  RTSP/USB stream
     │
     ▼
  ┌──────────────┐
  │ ThreadedCam  │  ← non-blocking read
  │ .read()      │
  └──────┬───────┘
         │  numpy frame (BGR)
         ▼
  ┌────────────────────┐
  │  InsightFace       │
  │  (buffalo_l)       │
  │                    │
  │  det_10g.onnx      │  → bbox + landmarks (5 points)
  │  1k3d68.onnx       │  → 68-point 3D landmark (สำหรับ Anti-Spoof)
  │  w600k_r50.onnx    │  → 512-d ArcFace embedding (FP32)
  └─────────┬──────────┘
            │
            ▼
  ┌──────────────────────┐
  │  Match Embedding     │
  │  cosine_sim(emb,     │      encodings.pkl
  │    known_norms)      │  ◄── (np.ndarray ของ 512d
  │  ≥ 0.35 → per_id     │       ที่ encode_faces_arcface.py
  │  < 0.35 → "Unknown"  │       สร้างไว้)
  └──────────┬───────────┘
             │ per_id
             ▼
  ┌──────────────────────┐
  │  SessionManager      │       External Personnel API
  │  .get_or_create()    │  ──HTTP GET /person/{per_id}──►
  │                      │  ◄────── ชื่อ/แผนก/ตำแหน่ง──────
  │  PersonInfo cache    │       (cache 10 นาที)
  └──────────┬───────────┘
             │
             ▼
  ┌──────────────────────────────────────┐
  │  Anti-Spoofing Pipeline (7 ด่าน)     │
  │  1. Landmark Depth (3D)              │
  │  2. Micro-Motion                     │
  │  3. Blink (EAR)                      │
  │  4. Texture (LBP+Laplacian+Chroma)   │
  │  5. Screen Border (FFT+Canny)        │
  │  6. Finger Challenge (MediaPipe)     │
  │  7. MiniFASNet (FAS deep model)      │
  │                                      │
  │  ครบทุกด่าน → confirmed=True          │
  └──────────────┬───────────────────────┘
                 │
                 ▼
  ┌────────────────────────────────────┐
  │  try_checkin(person)               │
  │                                    │
  │  POST http://localhost:8000/       │  ──── api.py ──────►  PostgreSQL
  │       attendance                   │                      attendance_logs
  │  body = {                          │                      INSERT (denormalized
  │    per_id, status='IN',            │                       — เก็บ snapshot
  │    name, organize_th, posname_th,  │                       ของ HR ณ เวลานั้น)
  │    organize_id, camera_name,       │
  │    check_time                      │
  │  }                                 │
  └─────────────┬──────────────────────┘
                │
                ▼
  ┌────────────────────────────────────┐
  │  PicSAVE: บันทึกภาพถาวร            │  ──► PicSAVE/YYYY/MM/DD/
  │  HH-MM-SS_{per_id}_IN.jpg          │      <ไฟล์>
  └────────────────────────────────────┘

  ── Check-Out Flow ──
  ถึง CHECKOUT_TIME → do_checkout() → POST /attendance status='OUT'
  ถ้าไม่มี IN วันนี้ → API reject (400)


4. Web UI Polling Flow (LiveCam + Dashboard)
=============================================

  Browser (React)                     stream_server.py        main.py
  ─────────────────                   ─────────────────       ───────
     │
     │  authFetch(/snapshot/cam1)
     │  + Authorization: Bearer ...
     ├────────────────────────────────►│
     │                                  │  jwt.decode()
     │                                  │  user OK
     │                                  │
     │                                  │  read _cam_frames[cam1]   ◄── push_frame()
     │                                  │  (in-memory dict)         │   ทุก ~120ms
     │                                  │  ← bytes (JPEG)            │
     │                                  │                            │
     │  200 OK + image/jpeg            │                            │
     │◄─────────────────────────────────┤                            │
     │                                                               │
     │  blob = await r.blob()                                       │
     │  URL.createObjectURL(blob)                                   │
     │  <img src={blobUrl}/>                                        │
     │                                                               │
     │  setTimeout 120ms → loop อีก                                 │
     │                                                               │
     │  authFetch(/state/cam1)         │                            │
     ├────────────────────────────────►│  return _cam_states[cam1]  ◄── push_state()
     │  ← JSON (faces[], persons[])    │                            │
     │                                                               │
     │  วาด canvas overlay บน frame                                  │
     │                                                               │

  หน้า Dashboard (FaceSnap blob loader):
   - ลองโหลด /snap/{camId}/{perId} จากกล้อง active ทีละตัว
   - ถ้า 200 → URL.createObjectURL(blob) → <img>
   - คลิก → FaceModal เปิด → load blob ใหม่ (independent lifecycle)

6. Audit Log Flow (Phase 1.5)
==============================

  ทุก mutating request → audit.log() → INSERT row

  Action vocabulary:
  ┌─────────────────────────────────┬──────────────────────────────────┐
  │  Action                          │  Target                          │
  ├─────────────────────────────────┼──────────────────────────────────┤
  │  auth.login.success / .fail     │  username                        │
  │  auth.password.change            │  user_id                         │
  │  camera.create / .update / .del │  cam_id                          │
  │  camera.activate / .reload       │  cam_id                          │
  │  system.start / .stop            │  -                               │
  │  system.cache_clear              │  -                               │
  │  system.window_toggle            │  ON/OFF                          │
  │  attendance.update / .delete     │  log_id=N                        │
  └─────────────────────────────────┴──────────────────────────────────┘

  Schema: audit_logs (id, ts, user_id, username, action, target,
                       ip, user_agent, details JSONB, success)

  ดูผ่าน:
  GET /audit/logs?limit=100&action=auth.login.fail&since=2026-05-06
  → admin เท่านั้น (require_admin)


7. Headless Mode IPC (main.py ↔ stream_server.py)
==================================================

  ตั้งแต่ v12 ใช้ HTTP push แทนการเขียนไฟล์:

  main.py (subprocess)              stream_server.py (parent process)
  ──────────────────                ─────────────────────────────────
     │                                       │
     │  POST /push/frame/cam1                │
     │  body = jpeg bytes                    │
     ├──────────────────────────────────────►│
     │                                       │  _cam_frames[cam1] = body
     │                                       │  (in-memory)
     │                                       │
     │  POST /push/state/cam1                │
     │  body = JSON                          │
     ├──────────────────────────────────────►│  _cam_states[cam1] = state
     │                                       │
     │  POST /push/snap/cam1/{perId}         │
     │  body = jpeg crop                     │
     ├──────────────────────────────────────►│  _cam_snaps[cam1][perId] = body

  ⚠ /push/* ยังไม่ guard — TODO: ใช้ shared INTERNAL_PUSH_TOKEN
     เพื่อกัน LAN attacker push frame ปลอม

============================

  ┌──────────────────────────────────────────────────┐
  │  Layer 1 — systemd                                │
  │  facereg-stream.service                           │
  │  Restart=always, RestartSec=3                     │

  └──────────────────┬───────────────────────────────┘
                     │
                     ▼ spawn subprocess
  ┌──────────────────────────────────────────────────┐
  │  stream_server.py — _watchdog_loop() thread       │
  │  ตรวจทุก 3 วิ:                                     │
  │   - main.py (face) ตายไหม?                         │
  │   - api.py (port 8000) ตอบไหม?                     │

  │   - rate limit: 5 restart/60s → disable + แจ้งใน  │
