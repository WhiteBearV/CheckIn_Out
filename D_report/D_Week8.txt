■ งานที่ดำเนินการในวันนี้
────────────────────────────────────────────────────────────────────────

1. ปรับและตรวจสอบสไลด์นำเสนอความคืบหน้าของโปรเจกต์ (ช่วงเช้า)
   ─────────────────────────────────────────────────────────────────
   ทบทวนและปรับปรุงสไลด์สำหรับนำเสนอความคืบหน้าของโปรเจกต์
   ระบบ Face Attendance ที่จะนำเสนอในวันที่ 7 พฤษภาคม 2569

   งานที่ดำเนินการ:
     - ตรวจสอบเนื้อหาสไลด์ให้ครบถ้วนและถูกต้อง
     - ปรับรูปแบบการนำเสนอให้ชัดเจนและเข้าใจง่าย
     - ทบทวนจุดเด่นและผลลัพธ์ที่ต้องการสื่อสาร

2. ปรับและตรวจสอบสไลด์การพูด 3 นาที หัวข้อ Agent Skill (ช่วงบ่าย)
   ─────────────────────────────────────────────────────────────────
   ทบทวนและปรับปรุงสไลด์สำหรับการพูด 3 นาที
   ในหัวข้อเรื่อง Agent Skill

   งานที่ดำเนินการ:
     - ปรับเนื้อหาสไลด์ให้เหมาะสมกับระยะเวลา 3 นาที
     - ตรวจสอบความถูกต้องและความครบถ้วนของเนื้อหา
     - ปรับการลำดับเนื้อหาให้ไหลลื่นและสื่อสารได้ชัดเจน

■ งานที่ดำเนินการในวันนี้
────────────────────────────────────────────────────────────────────────

1. ศึกษาโจทย์ Channel Bonding ด้วย Raspberry Pi 4
   ─────────────────────────────────────────────────────────────────
   ได้รับโจทย์ใหม่เรื่องการทำ Channel Bonding โดยใช้ Raspberry Pi 4
   เพื่อรวมการเชื่อมต่อหลายช่องสัญญาณให้เป็นช่องสัญญาณเดียว

   ขั้นตอนการศึกษา:
     1. พิจารณา Speedify เป็นตัวเลือกแรก
        - Speedify รองรับ Channel Bonding ได้ตรงตามความต้องการ
        - แต่ Speedify มีค่าใช้จ่ายในการใช้งาน จึงต้องหาทางเลือกอื่น

     2. ศึกษา OpenMPTCProuter เป็นทางเลือกทดแทน
        - OpenMPTCProuter เป็น open-source solution สำหรับ Channel Bonding
        - ต้องการ VPS (Virtual Private Server) สำหรับรัน Server ฝั่ง aggregation

2. ทดลองตั้งค่า VPS สำหรับ OpenMPTCProuter
   ─────────────────────────────────────────────────────────────────
   ดำเนินการทดลองตั้งค่าเครื่อง VPS เพื่อใช้งานร่วมกับ OpenMPTCProuter

   ปัญหาที่พบ:
     - เครื่องที่ใช้เป็น VPS ไม่สามารถหา IP Address ได้
     - เมื่อไม่มี IP ทำให้ไม่สามารถ SSH เข้าไปยังเครื่อง VPS ได้
     - ส่งผลให้ไม่สามารถดำเนินการติดตั้ง VPS Server ต่อไปได้

■ สรุปไฟล์ที่สร้าง / แก้ไข
────────────────────────────────────────────────────────────────────────

  [ไม่มีการแก้ไข source code] — งานวันนี้เป็นการศึกษาและทดลองตั้งค่า
  ระบบ Channel Bonding ด้วย Raspberry Pi 4 และ OpenMPTCProuter

■ เทคโนโลยีที่ใช้
────────────────────────────────────────────────────────────────────────

  - Raspberry Pi 4      — อุปกรณ์หลักสำหรับ Channel Bonding
  - Speedify            — Software สำหรับ Channel Bonding (มีค่าใช้จ่าย)
  - OpenMPTCProuter     — Open-source solution สำหรับ Channel Bonding
  - VPS                 — Virtual Private Server สำหรับรัน aggregation server
  - SSH                 — โปรโตคอลสำหรับเชื่อมต่อและจัดการ VPS

■ ปัญหาที่พบและแนวทางแก้ไข
────────────────────────────────────────────────────────────────────────

  ปัญหา : Speedify มีค่าใช้จ่ายในการใช้งาน ไม่เหมาะสำหรับการนำไปใช้งานจริง
  วิเคราะห์: Speedify เป็น commercial software ที่ต้องชำระค่าบริการ
             ทำให้ไม่สามารถใช้งานได้อย่างอิสระ
  แก้ไข : เปลี่ยนมาศึกษา OpenMPTCProuter ซึ่งเป็น open-source แทน

  ปัญหา : เครื่อง VPS ไม่สามารถหา IP Address ได้ ทำให้ SSH เข้าไม่ได้
  วิเคราะห์: เครื่องที่ใช้เป็น VPS ไม่ได้รับ IP Address
             จึงไม่มี endpoint สำหรับ SSH เพื่อติดตั้ง VPS Server
