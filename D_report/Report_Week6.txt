■ บทสรุปสำหรับผู้บริหาร (Executive Summary)
───────────────────────────────────────────────────────────────────────

  สัปดาห์นี้พัฒนาและปรับปรุง Web Dashboard ของระบบบันทึกเวลาด้วยใบหน้าใน
  4 ด้านหลัก ได้แก่ การแสดงรูปภาพพนักงาน ระบบแจ้งสถานะโหลด ฟีเจอร์ลงชื่อออก
  และโหมด CCTV นอกจากนี้ยังแก้ปัญหาภาพกล้องกระตุก แก้ไขเวลาไม่ตรง และ
  เผยแพร่ระบบขึ้น Docker Hub เพื่อให้ติดตั้งใช้งานได้จากหลายเครื่อง
  ปัญหาสำคัญทุกจุดที่พบในสัปดาห์นี้ได้รับการแก้ไขเรียบร้อยแล้วทั้งหมด


■ งานที่ดำเนินการสำเร็จ
───────────────────────────────────────────────────────────────────────

  1. พัฒนาระบบแสดงรูปภาพพนักงานบน Web Dashboard
     ─────────────────────────────────────────────────────────────────
     วัตถุประสงค์ : Dashboard เดิมไม่แสดงรูปพนักงานใดเลย ทำให้ผู้ดูแลระบบ
                    ระบุตัวตนพนักงานได้ลำบาก และไม่มีหลักฐานภาพยืนยัน
                    การเช็กชื่อเข้า-ออก
     ผลลัพธ์      : Dashboard แสดงรูปโปรไฟล์พนักงานจากระบบบุคลากรกลาง
                    และรูปที่ถ่ายขณะเช็กชื่อจริงจากกล้องได้อย่างถูกต้อง
                    แยกประเภทชัดเจน คลิกเพื่อขยายรูปเต็มจอได้ในทุกมุมมอง
     สถานะ       : ✅ เสร็จสมบูรณ์

  2. เพิ่มหน้าแสดงสถานะการโหลด AI พร้อม progress bar จริง
     ─────────────────────────────────────────────────────────────────
     วัตถุประสงค์ : เดิมเมื่อกด "เปิด" กล้องจะแสดงหน้าจอดำนิ่งนาน 20–60 วินาที
                    โดยไม่มีสัญญาณใดว่าระบบกำลังทำงานอยู่ ผู้ใช้ไม่ทราบว่า
                    ควรรอหรือเกิดข้อผิดพลาด
     ผลลัพธ์      : แสดงข้อความบอกขั้นตอนปัจจุบันแบบ real-time เช่น
                    "กำลังโหลด AI Model..." พร้อม progress bar ที่ขยับตาม
                    ความคืบหน้าจริงของระบบ ไม่ใช่ animation ปลอม
     สถานะ       : ✅ เสร็จสมบูรณ์

  3. เพิ่มฟีเจอร์ลงชื่อออกด้วยตนเองจาก Dashboard
     ─────────────────────────────────────────────────────────────────
     วัตถุประสงค์ : เดิมผู้ดูแลระบบไม่มีช่องทางแก้ไขให้พนักงานที่ลืมลงชื่อออก
                    ต้องแก้ไขตรงฐานข้อมูลซึ่งซับซ้อนและเสี่ยงต่อข้อผิดพลาด
     ผลลัพธ์      : เพิ่มปุ่ม "ลงชื่อออก" บนการ์ดพนักงาน กดได้เฉพาะรายที่
                    เข้างานแล้วแต่ยังไม่ได้ลงชื่อออก บันทึกเวลาออกอัตโนมัติ
                    และ Dashboard อัปเดตทันที
     สถานะ       : ✅ เสร็จสมบูรณ์

  4. พัฒนาโหมด CCTV สำหรับนอกเวลาทำงาน
     ─────────────────────────────────────────────────────────────────
     วัตถุประสงค์ : กล้องควรเปลี่ยนบทบาทจาก "บันทึกเวลาเข้างาน" มาเป็น
                    "กล้องวงจรปิด" โดยอัตโนมัติเมื่อออกนอกช่วงเวลาทำงาน
                    และ checkout พนักงานที่ยังไม่ออกทั้งหมดให้อัตโนมัติด้วย
     ผลลัพธ์      : ระบบตรวจสอบเวลาทุก 30 วินาที เมื่อออกนอกช่วงเวลาทำงาน
                    จะลงชื่อออกให้พนักงานทุกคนอัตโนมัติ และ Dashboard
                    เปลี่ยนเป็นโหมดแสดงภาพวงจรปิดเต็มจอ
     สถานะ       : ✅ เสร็จสมบูรณ์

  5. แก้ปัญหาภาพจากกล้องกระตุกบน Docker และเพิ่มประสิทธิภาพระบบ
     ─────────────────────────────────────────────────────────────────
     วัตถุประสงค์ : ภาพจากกล้องบน Web Dashboard กระตุกและหน่วง
                    ไม่สามารถใช้ติดตามสถานการณ์แบบ real-time ได้จริง
     ผลลัพธ์      : แก้ไขสาเหตุ 4 จุดพร้อมกัน ได้แก่ ลดการส่งภาพซ้ำ
                    ย้ายการเขียนไฟล์ภาพไปยัง RAM เพื่อลด latency ปรับการ
                    ตรวจจับใบหน้าให้เร็วขึ้น ~4 เท่า และปิด TensorFlow
                    บน CPU ที่เป็นต้นเหตุหลักของการค้าง ส่งผลให้ภาพไหลลื่น
                    ขึ้นอย่างเห็นได้ชัด
     สถานะ       : ✅ เสร็จสมบูรณ์

  6. เผยแพร่ระบบและเปิดให้เข้าใช้งานจากเครือข่าย LAN
     ─────────────────────────────────────────────────────────────────
     วัตถุประสงค์ : ระบบเดิมใช้งานได้เฉพาะบนเครื่องที่ติดตั้งโดยตรง
                    ไม่สามารถให้ผู้อื่นในเครือข่ายเข้าถึงได้
     ผลลัพธ์      : เผยแพร่ Docker image ขึ้น Docker Hub พร้อมใช้งานได้ทันที
                    เปิดให้เข้าใช้ Dashboard ผ่าน http://192.168.1.104/dashboard/
                    จากทุกเครื่องในเครือข่ายโดยไม่ต้องใส่หมายเลข port
     สถานะ       : ✅ เสร็จสมบูรณ์

     คาดว่าจะเสร็จ : สัปดาห์ที่ 7

■ ปัญหา / อุปสรรค ที่พบ
───────────────────────────────────────────────────────────────────────

  ประเด็น    : รูปภาพพนักงานไม่แสดงผลเมื่อใช้งานจริง (แต่แสดงได้ในระหว่างพัฒนา)
  ผลกระทบ   : Dashboard ที่พัฒนาแสดงรูปไม่ได้เมื่อ deploy จริง
  สถานะ     : แก้ไขแล้ว
  รายละเอียด : ระบบพัฒนาและระบบ deploy จริงมีการจัดการ URL ต่างกัน
               ทำให้ component เรียกหา endpoint ผิดตำแหน่ง แก้ไขโดยให้ทุก
               component อ่าน URL จากค่าตั้งในไฟล์ config แทนการกำหนดตายตัว

  ประเด็น    : โหมด CCTV ไม่ทำงานแม้จะตั้งค่าถูกต้อง
  ผลกระทบ   : ระบบไม่เปลี่ยนโหมดนอกเวลาทำงาน ทำให้ไม่มีการ checkout อัตโนมัติ
  สถานะ     : แก้ไขแล้ว
  รายละเอียด : พบว่าลำดับการตรวจสอบเงื่อนไขใน code ไม่ถูกต้อง ทำให้
               การตั้งค่าโหมด CCTV ไม่ถูกนำมาใช้ แก้ไขโดยสลับลำดับให้ถูกต้อง

  ประเด็น    : เวลาที่บันทึกในระบบช้ากว่าเวลาจริง 7 ชั่วโมง
  ผลกระทบ   : ประวัติการเข้างานทุก record แสดงเวลาผิด ใช้เป็นหลักฐานไม่ได้
  สถานะ     : แก้ไขแล้ว
  รายละเอียด : Container รันด้วยเวลามาตรฐานสากล (UTC) แทนเวลาไทย
               แก้ไขโดยกำหนด Timezone เป็น Asia/Bangkok ใน config ของ Docker

■ แผนงานในช่วงต่อไป (สัปดาห์ที่ 7)
───────────────────────────────────────────────────────────────────────

  เป้าหมายหลัก  : ทดสอบ Deploy บนเครื่อง Windows และปรับระบบให้พร้อมใช้งานจริง

  รายการงาน:
   1. ทดสอบติดตั้งและรันระบบบนเครื่อง Windows ด้วย Docker Desktop
   2. ปรับและทดสอบการเชื่อมต่อกล้อง IP (RTSP) บน Windows
   3. จัดทำเอกสารขั้นตอนการติดตั้งสำหรับผู้ใช้ทั่วไป


■ สิ่งที่ได้เรียนรู้ / ข้อสังเกต
───────────────────────────────────────────────────────────────────────

  สัปดาห์นี้ได้เรียนรู้ว่าระบบที่ทำงานได้ดีในระหว่างพัฒนาอาจมีพฤติกรรม
  แตกต่างออกไปอย่างสิ้นเชิงเมื่อนำไปใช้งานจริง เนื่องจากความแตกต่างของ
  environment เช่น การจัดการ URL การตั้งค่า timezone และประสิทธิภาพของ
  hardware ดังนั้นการทดสอบบน environment จริงตั้งแต่ช่วงต้นจึงสำคัญมาก

  นอกจากนี้ยังได้เรียนรู้การวิเคราะห์ปัญหาที่มีหลายสาเหตุซ้อนกัน เช่น
  ปัญหาภาพกระตุกที่มาจาก 4 จุดพร้อมกัน การแก้เพียงจุดเดียวไม่เพียงพอ
  ต้องระบุและแก้ทุกสาเหตุพร้อมกันจึงจะเห็นผลจริง
