■ Docker (วิธีหลัก — รันผ่าน Container)
────────────────────────────────────────────────────────────────────────

  เริ่มระบบ (ครั้งแรก / หลัง rebuild):
    docker compose -f docker/docker-compose.yml up -d --build

  เริ่มระบบ (ปกติ ไม่ rebuild image):
    docker compose -f docker/docker-compose.yml up -d

  หยุดระบบ:
    docker compose -f docker/docker-compose.yml down

  ดู log realtime:
    docker compose -f docker/docker-compose.yml logs -f

  ดู log เฉพาะ service:
    docker compose -f docker/docker-compose.yml logs -f api
    docker compose -f docker/docker-compose.yml logs -f db

  ตรวจสถานะ container:
    docker compose -f docker/docker-compose.yml ps

  Restart ระบบ (ไม่ rebuild image):
    docker compose -f docker/docker-compose.yml restart

  Restart เฉพาะ service:
    docker compose -f docker/docker-compose.yml restart api
    docker compose -f docker/docker-compose.yml restart db

  Restart แบบ down+up (หยุดแล้วเริ่มใหม่ สะอาดกว่า):
    docker compose -f docker/docker-compose.yml down && docker compose -f docker/docker-compose.yml up -d

  Restart พร้อม rebuild image (หลังแก้ไข code):
    docker compose -f docker/docker-compose.yml down && docker compose -f docker/docker-compose.yml up -d --build

  เปิด URL หลังรัน:
    http://localhost:8000/dashboard/    ← Web Dashboard
    http://localhost:8000/docs          ← API Docs (Swagger)

  โครงสร้างไฟล์ภาพ (PicSAVE):
    PicSAVE/YYYY/MM/DD/HH-MM-SS_{per_id}_IN.jpg    ← รูป full frame ตอน check-in
    PicSAVE/YYYY/MM/DD/HH-MM-SS_{per_id}_FACE.jpg  ← face crop ตอน check-in
    PicSAVE/YYYY/MM/DD/HH-MM-SS_{per_id}_OUT.jpg   ← รูปล่าสุดที่เจอก่อน check-out

  โครงสร้างไฟล์ Live (live/):
    live/live_frame.jpg              ← frame ล่าสุดจากกล้อง (single-cam)
    live/live_state.json             ← session state (single-cam)
    live/live_frame_{cam_id}.jpg     ← frame กล้อง id (multi-cam)
    live/live_state_{cam_id}.json    ← session state กล้อง id (multi-cam)


■ Docker Hub (Push / Pull image)
────────────────────────────────────────────────────────────────────────

  Build dashboard ก่อน push (อัปเดต static/):
    cd dashboard && npm run build

  Build Docker image:
    cd docker
    docker compose build --no-cache api

  Tag และ Push ขึ้น Docker Hub:
    docker tag docker-api photcharap/face-attendance:latest
    docker login
    docker push photcharap/face-attendance:latest

  Pull และรันที่เครื่องอื่น:
    docker pull photcharap/face-attendance:latest
    docker compose -f docker/docker-compose.yml down && docker compose -f docker/docker-compose.yml up -d

  ตรวจสอบ env var ใน container (ยืนยัน API URL ถูกต้อง):
    docker compose -f docker/docker-compose.yml exec api python3 -c "import os; print('URL:',os.environ.get('EXTERNAL_API_URL'))"

  ดู log แบบ filter realtime:
    docker compose -f docker/docker-compose.yml logs -f api | grep --line-buffered "API CLIENT"

■ Face Recognition (main.py — รันบนเครื่อง host โดยตรง)
────────────────────────────────────────────────────────────────────────

  รันด้วย profile เริ่มต้น:
    python main.py

  รันด้วย profile กล้องหลัก:
    python main.py cam_main

  รันด้วย profile ทดสอบ:
    python main.py test

  รันด้วย env var:
    FACE_PROFILE=cam_usb python main.py

  สร้าง/อัปเดต face encodings:
    python encode_faces_arcface.py

■ Database (PostgreSQL)
────────────────────────────────────────────────────────────────────────

  เชื่อมต่อ DB ใน Docker container:
    docker exec -it face_db psql -U face_user -d face_attendance

  เชื่อมต่อ DB local:
    psql -U face_user -h localhost -d face_attendance

  รัน migration script:
    psql -U face_user -h localhost -d face_attendance -f migrate_v9.sql

  Export ข้อมูล:
    PGPASSWORD=1234 pg_dump -U face_user -h localhost face_attendance > backup.dump

  Import ข้อมูล:
    PGPASSWORD=1234 psql -U face_user -h localhost face_attendance < backup.dump


■ Venv (Python virtual environment)
────────────────────────────────────────────────────────────────────────

  เปิดใช้:
    source venv/bin/activate

  ติดตั้ง dependencies ทั้งหมด:
    pip install -r requirements.txt
